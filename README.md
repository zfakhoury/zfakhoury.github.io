# zfakhoury.github.io

My personal portfolio website.

## Live

[zfakhoury.github.io](https://zfakhoury.github.io)

## Stack

- Next.js (static export)
- Tailwind CSS
- next-intl (English / French)
- next-themes (light / dark mode)
- Framer Motion
- GitHub Pages (via GitHub Actions)

## Development

```bash
npm install
npm run dev
```
